📚 AI Research Assistant

📌 Project Overview AI Research Assistant is a Retrieval-Augmented Generation (RAG) application that helps researchers, students, and professionals perform academic literature analysis efficiently.

The system retrieves research papers from OpenAlex, builds a vector database using embeddings, and leverages a local LLM through Ollama to generate: ✦Research Analysis ✦Literature Reviews ✦Citation Extraction ✦Research Gap Identification ✦Trend Analysis ✦Paper Summarization ✦Research Comparison ✦Knowledge Discovery The project combines academic search, vector retrieval, and Generative AI into a single research workflow.
